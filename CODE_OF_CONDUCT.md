# Code of Conduct

* Janji Kami: Kami berkomitmen untuk menciptakan lingkungan yang ramah dan inklusif.
* Standar Kami: Bersikap hormat, menerima kritik membangun, dan fokus pada apa yang terbaik bagi komunitas.
* Tanggung Jawab Penegakan: Pengelola proyek bertanggung jawab untuk mengklarifikasi standar perilaku yang dapat diterima.
* Ruang Lingkup: Panduan ini berlaku dalam semua ruang proyek.
* Penegakan: Kasus perilaku kasar, melecehkan, atau tidak dapat diterima lainnya dapat dilaporkan.
* Pedoman Penegakan: Tindakan akan diambil berdasarkan tingkat keparahan pelanggaran.
* Atribusi: Dokumen ini disesuaikan dari Contributor Covenant.
